Discord / Cloudflare - временный фикс (Lite / Zapret 1 / любой Zapret)

Файлы:
  DiscordCloudflareFix.cmd   - запускайте этот файл (двойной клик)
  DiscordCloudflareFix.ps1   - реализация, вручную не нужен
  discord-candidates.json   - пул рабочих IP

Как поставить:
  1. Распакуйте архив в любую постоянную папку.
  2. Запустите DiscordCloudflareFix.cmd (двойной клик).
  3. Нажмите Да в UAC.
  4. В меню выберите 1 - Установить фикс.

Как проверить:  запустите .cmd снова и выберите 2.
Как удалить:   запустите .cmd снова и выберите 3.

Что создаётся:
  - задача Планировщика DiscordCloudflareFix (SYSTEM, при старте Windows);
  - локальный DNS 127.0.0.1:53;
  - NRPT-правила и hosts-блок для Discord/Cloudflare/авторизации.

ВАЖНО:
  - Это временный обход, не VPN. Стримы могут флапать.
  - Не запускайте одновременно с фиксом внутри Zapret 2:
    сначала отключите встроенный фикс (конфликт порта 53).
  - Если перенесли папку - запустите install заново.
  - Нужны права администратора.
