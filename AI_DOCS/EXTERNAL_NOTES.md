## 1. tspu-docs — как реально работает ТСПУ (EcoFilter)

- **Блокировка HTTPS = только по SNI** (17.5.3): URL/путь в HTTPS не видны.
  HTTP: блок → редирект 302 на заглушку. HTTPS: содержимое зашифровано → RST.
- **`send RST off` — ВСЕГДА включён** (17.1.2) 🚨: при блокировке RST не шлётся,
  соединение дропается молча («висит» до таймаута) — ровно наш симптом 000.
  Причина: при RST-блоке мессенджеры бесконечно реконнектят → нагрузка на фильтр.
- **Деградация протоколов** (17.3): capacity 0-100; 1-99 = **вероятностный дроп
  пакетов** → «плавающие» 000; «репиты пробивают» работает против него
  (заваливание пакетами повышает шанс прохода).
- **DPI-листы** (17.4): blacklist (default) — совпало со списком → действие;
  whitelist не используется.
- **Двухстадийная блокировка** (8, 23.3, «5-15 минут»): фильтр распознаёт →
  логи в ЦСУ со ВСЕХ площадок (~350, ~5000 устройств) → очистка от ложных →
  списки IP+порт на фильтры (HTTP) и Eco Highway (BGP). До обновления списка
  существующие сессии не рвутся → блоки «плавают» во времени.
- **DPI Engine: многофакторный анализ СЕССИИ, не пакета** (23.1): размеры
  пакетов + вариации, частоты, паттерны. Для шифрованного — только косвенные
  статистические признаки → наш фейк+повторы меняют «профиль сессии» на
  google-подобный, классификатор путается (не «тупая долбёжка»).
- **Обфускация и гонка вооружений** (23.4): простая обфускация распознаётся;
  притворяется другим — сложно; **качественная имитация — распознать
  НЕВОЗМОЖНО**. repeats — тактический выигрыш (паттерн «всплеск одинаковых
  пакетов» тривиально маркируется); вектор — имитация реального трафика
  (tls_client_hello_clone, tls_mod=rnd,dupsid, oob).

## 2. b4 — механики обхода, что взять для lua

- **SNI-first в ClientHello — критично для ТСПУ** (tlsgen/generator.go): fast-path
  для whitelisted доменов при SNI первым расширением. Проверка НАШИХ блобов:
  google/max_ru/web_max_ru — SNI **0** (first) ✅; sochi_park — **1** ⚠️.
  Проверено батареей (09-10): позиция SNI на Т2 НЕ критична (sochi_park с
  repeats пробивает) — но для других сетей SNI-first остаётся правилом.
  `tools/make_blob.py` уже генерирует SNI-first (SNI первым расширением +
  синтетический key_share).
- **Десинк «наоборот» — фейки RST/FIN/ACK** (nfq/desync.go): каждый фейк с
  ИСПОРЧЕННОЙ TCP-суммой (`corruptTCPChecksum`) — сервер дропает, DPI читает;
  RST с seq-10000/0/+10000; ACK futureSeq/futureAck; TTL убывает с каждым фейком;
  combo = RST+FIN+ACK с задержками 50-500 мкс. Проверено на Т2: **не работает**
  (RST-off, молчаливый дроп) — кандидат для сетей, где RST реально шлётся.
- **Динамический TTL** (`dynamicTTL`): TTL фейка ≤ реального TTL — у нас
  `ip_autottl=delta,min-max`.
- **RST protection** (README): поддельные RST от DPI отличаются по TTL/флагам/
  опциям — можно дропать (в winws2/lua такого НЕТ; идея).
- Остальное (не переносится 1-в-1): QUIC sniff/parse, MTProto proxy, DNS
  redirect/фрагментация (у нас hosts), Discovery/Watchdog (у нас тестер+вердикт),
  escalation chains (у нас auto.txt circular).
