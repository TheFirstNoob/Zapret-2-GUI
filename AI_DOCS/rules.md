# Zapret 2 GUI — правила и опыт

> Обновлено 2026-10-24. Актуальная версия — Pre-Release 0.10 + коммиты после
> релиза. Главная памятка — `AGENTS.md`; методика — `STRATEGY_GUIDE.md`;
> исторические испытания — `archive/STRATEGY_TRIALS.md`.

## 0. `default.txt`

Базовый пресет для большинства проверенных сетей: 7 блоков (Discord
Voice/Media/TLS, Google TLS, General TCP, QUIC Google/General). Это не
гарантия на любом маршруте: проблемные сети/регионы требуют отдельного
профиля и проверки.

## 1. Ключевые правила движка

- `--payload` обязателен: без него fake/multisplit не знает, что искать.
  TLS — `tls_client_hello`, HTTP — `http_req`, QUIC — `quic_initial`,
  Discord voice — `discord_ip_discovery`; unknown UDP — `:payload=all`.
- `repeats`: Discord — 8 (запас), YouTube — 6, General TCP — 8, QUIC — без
  повторов. Не увеличивать «на всякий случай».
- `nodrop` на SNI-блоках ломает цель: оригинал идёт за фейком, DPI видит оба.
  Discord-блоки — в drop-режиме.
- `tcp_ts` — только на fake; на multisplit запрещён (PAWS).
- Debug `--debug=@log` — дорого; `--debug=1` ломает захват.
- Имя блоба не начинать с цифры; `--lua-init` — только `--lua-init=@path`.

## 2. Zapret 1 vs Zapret 2

| | nfqws1 (Zapret 1) | lua-desync (Zapret 2) |
|---|---|---|
| Комбинирование | `--dpi-desync=fake,multisplit` | отдельные `--lua-desync=...` |
| Fooling | глобально | аргумент функции (`tcp_ts`) |
| Блобы | путь в аргументе | `blob=NAME` из `--blob` |

Ключевое отличие: в z2 несколько правил идут по порядку, побеждает первое
совпавшее; `--new` разделяет профили.

## 3. Тестирование

- Только `curl.exe` (`-4 -s -m 8`, браузерный UA); не aiohttp.
- Канарейка: `www.google.com`; тестовые: Discord, YouTube, Google, GitHub.
- Контрольные/шумные домены — отдельно; не смешивать с rate.
- `network_rate` — сетевые результаты без пингов и QUIC-класса.
- Один параметр — одна гипотеза. Кандидат проверять на fail-наборе,
  полигоне и CDN A/B; проигравший пресет не удалять.
- Тестер может быть зелёным, если проверяет не тот эндпоинт: SYN-блэкхол
  к AWS/Vivox и игровым серверам fake/split не лечит.

## 4. Что не работает / не тратить время

- `--debug=1`; aiohttp; короткие 8.3-пути с `@`-префиксом в основном запуске.
- IP-блоки (SYN-блэкхол) — не зона десинка; нужен другой маршрут/WARP.
- Break-класс CDN (DO/Hetzner/OVH/Vultr/BuyVM) — широкий ipset/десинк вредит.
- Слепое вливание чужих пресетов/ipset — ломает CDN/сети.

## 5. Служба и запуск

- Основной запуск — Popen/`@conf`; bat — фолбэк. binPath службы — Win32 API,
  чтение ImagePath из реестра (не `sc qc` на длинных путях).
- Перед удалением/остановкой — остановить обход; `Start=4`/`DeleteFlag=1`
  у WinDivert — норма.
- Игровые UDP-правки применяются только после переустановки службы; списки —
  к новым подключениям без рестарта.

## 6. Auto Hostlist

`--hostlist-auto=<путь>` (без `@`) в General/QUIC-блоках; файл
`lists/zapret-auto.txt` создаётся автоматически. Для UDP/игр/voice
hostname часто отсутствует — автолист неприменим.

## 7. Код-стайл

- Нет `time.sleep()` в async; `await asyncio.sleep()`.
- Одна функция — одна ответственность; утилиты — в `core/utils.py`.
- Текстовые файлы — UTF-8 без BOM; `.bat/.cmd` — chcp 65001 + CRLF.
- Вызовы `tasklist/sc/curl` — `encoding="oem", errors="replace"`.
- Пользовательские тексты — от первого лица («я»); технические комментарии —
  безликие.

### Стиль русских текстов

- Обычные кавычки `"..."`; без `;`; дефис вместо длинного тире.
- Не путать «Zapret 2» с числительным: «два обхода».
- Дробить абзацы; расшифровывать жаргон; ключевое выделять жирным.
- В UI пунктуацию оптом не менять — только точечно по скриншоту.
