# Стратегический роадмап

> Обновлено 2026-10-24. Принципы и текущий бэклог; исторические кандидаты и
> прогоны удалены при чистке.

## 0. Принципы

1. Один параметр — одна гипотеза о DPI. Без гипотезы не добавлять.
2. Модификатор встраивается в вызов при сборке пресета, не дописывается в
   конец цепочки.
3. Пользователь получает стратегию, списки и тогглы, а не набор сырых
   модификаторов.
4. Кандидат обязан пройти fail-набор, полигон и CDN A/B; «больше пробивает»
   не равно «лучше».
5. `--new`-сегментация: каждый сервис — свой блок; смешивать победителей по
   блокам можно (custom).

## 1. Текущий статус

- **default/default-alt** — база; Discord-блоки на repeats=8.
- **auto** — `circular` (3 неудачи до ротации); на проблемных сетях не
  гарантия, проверять живым прогоном.
- **tcpmd5-fake** — кандидат, прошедший Т2; в релизе.
- **ipset_catchall** — opt-in; широкий ipset лечит stateful-DPI, но ломает
  break-класс CDN. По умолчанию выключен.
- **Игры** — UDP-пулы по `(cutoff,repeats,wide)`; Wardogs 4192-4194;
  repeats=1 — слабое место на lossy-маршрутах, тестовый `flaky` проверяет
  repeats=12/реальный блоб.
- **Discord media/stream** — открытый кейс: z1 держит, z2 default/auto не
  подтверждены; чистый multisplit — кандидат, не «готовое исправление».
- **WebView2** — preflight + auto/`--browser` fallback; остаточные проверки
  в `PLAN_WEBVIEW2_FALLBACK.md` (не стратегия).

## 2. Что можно проверять дальше

| Идея | Условие |
|---|---|
| `repeats` для игрового UDP | после `flaky` на реальном сервере |
| Реальный `ACTIVE_GAME_UDP` для игр | сравнить с `quic_google` |
| Широкий UDP для новых регионов | только с CIDR/риском для CDN |
| `tcp_md5` / `tls_mod` | по одной гипотезе, с CDN A/B |
| Pure multisplit для Discord media | длительный тест, не один вызов |
| IP/route-диагностика | SYN-блок не лечится стратегией |

## 3. Что не делаем

- IP-блоки (SYN-блэкхол) — вне зоны десинка; другой маршрут/WARP.
- Break-класс CDN (DO/Hetzner/OVH/Vultr/BuyVM) — широкий десинк вредит.
- Слепое вливание чужих пресетов/ipset.
- Вероятностные оркестраторы в пользовательских пресетах.
- Бандл Fixed Version WebView2 без отдельного решения.

## 4. Закрытые направления

- «Гонка репитов» и не-репитные кандидаты на Т2 — закрыты/исторические.
- Широкий ipset как универсальное лечение — отклонён.
- Голосовые пины Discord hosts — запрещены (ротация серверов).
- Порт 16kb-семейства и OOB/syndata — только эксперименты, не релиз.
