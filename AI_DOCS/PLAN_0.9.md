## СДЕЛАНО (кратко, чтобы не переделывать)

- **Безопасность**: подписанные обновления (Ed25519, PUBKEY `f6a4a0…72e`,
  отпечаток `50DCECF29451`), fail-closed апдейтер, офлайн-ключ + инструменты
  (`tools/security/`), чеклист выпуска `AI_DOCS/RELEASE_CHECKLIST.md`.
- **Discord**: база переведена в drop-режим (доказана утечка полного hello),
  повторы только на fake; ALT-режим (nodrop) — тумблер в экспертных + галочка
  в тестере.
- **Wardogs**: рецепт найден и в продукте — вкладка «Игровые блокировки»
  (домены авторизации + UDP-фикс `fake:...:payload=all`, порт 4192 и
  диапазоны 54.115/54.228/54.216/3.218). Баг-корень: lua fake/udplen по
  умолчанию не трогают unknown-UDP (нужен `payload=all`), GameFilter=udp
  в лаунчере был из-за этого холостым — исправлен.
- **Сборка**: `Zapret2GUI.spec` (впервые в гите): исключены
  cryptography/bcrypt, отфильтрованы корневые дубли cygwin1/WinDivert и
  Python.Runtime.xml; версия exe генерируется из `core.config.VERSION`.
  Итог: exe 18.5 → **13.7 МБ**, zip 18.3 → **13.5 МБ**.
- **WinDivert**: разобраны ложные тревоги диагностики (путь с пробелами;
  Start=4/DeleteFlag=1 — НОРМА WinDivert). Починен реальный хвост
  «помечена на удаление» (остановка обхода → выгрузка драйвера → пересоздание).
- **Тестер**: строки больше не зависают в «тестируется…» (сервер отдаёт
  `completed`, фронт закрывает по одному разу); «голый тест» закрывается при
  переходе; «Хосты» = `зачётные/зачётные (всего)`, подсказка на заголовке.
- **Навигация/главная**: 3 основных пункта + сворачиваемая группа
  «Экспертные инструменты» с категориями; «Параметры запуска» Zapret 2 —
  РАЗВЁРНУТЫ по умолчанию (решение юзера), «Zapret 1» — свёрнут.
  «Проверить работу» реально запускает диагностику.
- **Доки**: правила (первое лицо «я» в пользовательских текстах),
  README (признаки подделок, каналы), ченджлог 0.9, чистка мусора и
  .gitignore (backups/updates/games/etl…).
- **README — стиль по отзыву друзей**: жаргон → понятные слова, обычные
  кавычки вместо «ёлочек», без `;` и длинных тире, интро сокращено,
  «Быстрый старт» переехал наверх, «Возможности» — таблицей, FAQ — списками,
  добавлен «Словарь» (13 терминов), починены b4/защитник/два обхода.
  Правила стиля — в `rules.md` (в UI пунктуацию НЕ менять оптом).

### Задачи на 0.9 (обновлено 2026-09-24)
- [~] **winws2 1.0.5 → 1.0.5.2** — по логам апстрима: 1.0.5.1 ускоряет поиск
  профиля (простые проверки первыми, CPU до −10× при СОТНЯХ/ТЫСЯЧАХ профилей
  с --filter-mark), 1.0.5.2 — ещё быстрее dp_match. У нас 7-8 профилей на
  пресет, так что выгода почти нулевая. Обновление не срочное: сделать по
  случаю (заменить bin/winws2.exe + lua, если менялись), прогнать тестер.
- [ ] Ревизия release-набора пресетов — по желанию, после winws2.

### Решения по трём вопросам (2026-09-24, коммит см. ниже)
1. **Zapret 1 fallback** — панель скрывается, если Zapret 1 в системе нет
   (нет настроенной папки, службы `zapret` и winws.exe). Есть — показывается
   как раньше (свёрнутая, «запасной вариант»). Сервер отдаёт
   `zapret1.installed` в `/api/status` (кэш на сеанс).
2. **winws2 1.0.5.2** — см. выше: оптимизация про большие наборы профилей,
   у нас выгоды нет; не срочно.
3. **Lite-версия** — она не «отдельный код», а сборка тех же исходников
   (`build_lite.py` копирует bin/lua/blobs/lists/presets, генерит батники,
   манифест). Актуализировано: в архив пишутся `VERSION` и дата в README,
   а сборка САМА прогоняет dry-run всех release-пресетов (11/11) и падает
   при ошибке — «отставание» теперь видно и сломать архив не выйдет.

## ЗАПАСНЫЕ ПЛАНЫ (если появится нетипичный блок)

- **YouTube/QUIC, если однажды пробьёт по-новому.** Обычный обход
  (fake + блоб) стабилен: вмешиваться в QUIC почти не можем, а разные блоки
  у разных провайдеров уже учтены. Если появится нетипичный блок видео:
  1) вручную добавить 2–3 ключевых поддомена googlevideo в «в обход»
     (либо всю поддоменную сеть — почти штатно и так покрыта);
  2) только как эксперимент — `--wf-udp-in=443` + авто-список, чтобы
     winws2 видел входящий QUIC и заносил медиа-домены сам.
     Минус: список может сильно раздуться и постоянно дёргать авто-список,
     поэтому по умолчанию не включаем.
