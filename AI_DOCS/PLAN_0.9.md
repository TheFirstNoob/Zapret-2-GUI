## СДЕЛАНО (кратко, чтобы не переделывать)

- **Безопасность**: подписанные обновления (Ed25519, PUBKEY `f6a4a0…72e`,
  отпечаток `50DCECF29451`), fail-closed апдейтер, офлайн-ключ + инструменты
  (`tools/security/`), чеклист выпуска `AI_DOCS/RELEASE_CHECKLIST.md`.
- **Discord**: база переведена в drop-режим (доказана утечка полного hello),
  повторы только на fake; ALT-режим (nodrop) — тумблер в экспертных + галочка
  в тестере.
- **Wardogs**: рецепт найден и в продукте — вкладка «Игровые блокировки»
  (домены авторизации + UDP-фикс `fake:...:payload=all`, порт 4192 и
  диапазоны 54.115/54.228/54.216/3.218). Баг-корень: lua fake/udplen по
  умолчанию не трогают unknown-UDP (нужен `payload=all`), GameFilter=udp
  в лаунчере был из-за этого холостым — исправлен.
- **Сборка**: `Zapret2GUI.spec` (впервые в гите): исключены
  cryptography/bcrypt, отфильтрованы корневые дубли cygwin1/WinDivert и
  Python.Runtime.xml; версия exe генерируется из `core.config.VERSION`.
  Итог: exe 18.5 → **13.7 МБ**, zip 18.3 → **13.5 МБ**.
- **WinDivert**: разобраны ложные тревоги диагностики (путь с пробелами;
  Start=4/DeleteFlag=1 — НОРМА WinDivert). Починен реальный хвост
  «помечена на удаление» (остановка обхода → выгрузка драйвера → пересоздание).
- **Тестер**: строки больше не зависают в «тестируется…» (сервер отдаёт
  `completed`, фронт закрывает по одному разу); «голый тест» закрывается при
  переходе; «Хосты» = `зачётные/зачётные (всего)`, подсказка на заголовке.
- **Навигация/главная**: 3 основных пункта + сворачиваемая группа
  «Экспертные инструменты» с категориями; «Параметры запуска» Zapret 2 —
  РАЗВЁРНУТЫ по умолчанию (решение юзера), «Zapret 1» — свёрнут.
  «Проверить работу» реально запускает диагностику.
- **Доки**: правила (первое лицо «я» в пользовательских текстах),
  README (признаки подделок, каналы), ченджлог 0.9, чистка мусора и
  .gitignore (backups/updates/games/etl…).
