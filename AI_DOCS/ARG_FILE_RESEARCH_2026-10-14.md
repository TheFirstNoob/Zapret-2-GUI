## 1. Что говорит движок (исходники)

- Help (`zapret2-v1.0.2\nfq2\nfqws.c:1808`):
  ` @<config_file>|$<config_file> ; read file for options. must be the only
  argument. other options are ignored.`
- Код (`nfqws.c:2279-2281`):
  `if (argc >= 2 && (argv[1][0] == '@' || argv[1][0] == '$')) config_from_file(argv[1] + 1);`
- **Важно:** это СОБСТВЕННАЯ фича winws2/nfqws, а не «response-файлы Cygwin CRT»
  (как предположило внешнее ревью). `config_from_file` ещё не прочитан —
  правила токенизации (кавычки/пробелы) в источнике не сверены (см. §5).
- Бинарь: winws2 v1.0.5 (`0b8182d`), lua_compat_ver 6. Локальные исходники:
  `C:\Users\TheFirstNoob\Desktop\Zapret 2 GUI\zapret2-v1.0.2`.

## 3. Выводы (рабочие правила на сейчас)

1. **`@file` — рабочий механизм.** Лимит длины снят полностью (файл безлимитный);
   комбинация с `--dry-run` для валидации сохраняется.
2. **Пробелы в ЗНАЧЕНИЯХ путей внутри файла — не поддержаны** ни одним из
   проверенных способов экранирования (без кавычек/полный токен/только путь/
   бэкслеш — все ❌). Следствия:
   - абсолютные пути в конфиге — только если корень БЕЗ пробелов;
   - относительные пути + `--chdir=<корень>` — но `--chdir` сам обязан быть без
     пробелов (при пробелах без кавычек — краш; кавычки под вопросом, C6);
   - fallback для установок с пробелами (напр. «Zapret 2 GUI»): 8.3-короткий
     `--chdir` (GetShortPathNameW; только если 8.3 включён) ИЛИ junction на
     короткий путь (если 8.3 выключен) ИЛИ оставить прямой argv-режим для таких
     установок (argv с пробелами РАБОТАЕТ — list2cmdline/argv).
3. **Не торопиться со схлопыванием пресетов** (дедуп Discord-блоков, стрип
   `--comment`): с `@file` длина не критична; делать только с golden A/B.

## 4. Черновик миграции (когда решим; НЕ начато)

1. `launcher.write_run_conf(root, path)` — токены в файл (LF, `=`-форма);
   запуск: `winws2 @<conf>`.
2. Служба: `binPath = "winws2.exe" @C:\...\service_run.conf` (~80 симв);
   смена стратегии/игр = **перезаписать файл + restart** (без ChangeServiceConfigW).
3. bat-фолбэк: `start /min winws2.exe @conf` (в bat попадает только путь к conf;
   ASCII-проблема `write_run_bat` (ascii+errors=replace) уходит, если путь conf
   без пробелов — иначе см. §3.2).
4. `validate_args`: писать временный conf и `--dry-run @conf` (T1 показал, что
   это работает), либо оставить прямой argv (32К хватает).
5. Golden перед миграцией: conf-снапшоты по всем `presets/*.txt` × тогглам;
   сверка `profiles loaded` (default = 8) и dry-run; прямой argv — как fallback.

## 5. Что осталось проверить (точки продолжения)

1. **`config_from_file` в исходниках** — правила токенизации (кавычки/пробелы/
   строки), отличие `$` от `@`. Грепнуть определение + чтение.
2. Почему T1 сработал при `argv[1]="--dry-run"` (в nfqws-коде @ только argv[1] —
   вероятно, у winws2 свой main; проверить winws2-специфику).
3. **C6-повтор**: кавычки на `--chdir` с полным валидным конфигом — если
   кавычки всё-таки работают, проблема пробелов решается штатно.
4. PoC службы: `@file` в binPath + restart-флоу.
5. bat-фолбэк с `@file`.

## 6. Принятые, но НЕ сделанные хвосты (из внешнего ревью 14.10)

Эти пункты подтверждены по коду, но не реализованы (в порядке обсуждения):
