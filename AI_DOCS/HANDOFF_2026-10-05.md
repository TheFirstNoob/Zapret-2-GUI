## 5. Правила, которые НЕЛЬЗЯ нарушать (проверены на практике)

- **Git:** только через `git -C "<путь>"`, без `cd`. Коммит сообщением через
  `-F файл`. Push не делаю. В зеркале код не править (ff-only сломается).
- **Зеркало «грязное» — норма.** `M lists/*-user.txt`, untracked
  `--wf-tcp-out`, `README.txt`, `install.cmd`, `main.pyw`, `python/`.
- **`sc`** — только `sc.exe` (алиас = Set-Content, создаёт файлы!).
  `cat.exe`, `sort.exe`, `head`, `tail`, `wc`.
- **Кодировки:** UTF-8 без BOM. `.bat` — CRLF (через `newline=""`) + ASCII
  или `chcp 65001`. Инлайн `python -c` с вложенными кавычками ломает
  IDE → писать скриптом файлом в `Temp\opencode`.
- **Инлайн `python -c` в PowerShell** ломается на `\S`, `{`, `}` —
  использовать файл-скрипт.
- **Правка отступов через python-скрипт** в `process_probe.py` уже ломала файл
  (добавил лишние 4 пробела) — аккуратно, проверять `py_compile` сразу.
- **Windows `os.replace` занятого файла** → `PermissionError [WinError 32]`
  при параллельной записи: temp-имена делать уникальными.
