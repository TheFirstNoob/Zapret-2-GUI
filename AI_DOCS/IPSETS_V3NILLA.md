## Правила использования

1. **НЕ вливать целиком**: ipset-десинк по «недоступным» подсетям лечит
   fix-класс (AWS/Akamai/CF — stateful-DPI), но ломает break-класс
   (DO/Hetzner/OVH — их же подсети в списке!). Наш A/B это подтвердил.
2. Применение: точечно через ipset-include-user («Спорные домены»),
   после каждого добавления — проба сервиса.
3. Для массового обновления: дифф-слияние + CDN A/B-сверка после
   применения. Их AS Parser — референс для авто-сбора с RIPE (задача 0.8:
   фича «Обновить ipset-базу»).
4. exclude.txt/exclude-domains.txt — сверить с нашим list-exclude.txt
   (steam/yandex-семейства и т.п.) на предмет пропущенных исключений.
