# UI Rework Implementation Plan (Zapret 2 GUI 0.5 → 0.6)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Перестроить Главную (одна карточка «Обход») и Тестер (живой вывод блоками по стратегиям, единый вердикт) без смены палитры.

**Architecture:** Чисто фронтенд: index.html (разметка), css/app.css (стили блоков), js/app.js (группировка живых строк по `data.profile`, делегированный обработчик, чип-опции). Сервер уже шлёт `profile` в results (0cf0985) — backend не трогаем, кроме мелкой правки текста прогресса, если нужна.

**Tech Stack:** Vanilla JS, HTML/CSS (webview SPA), без зависимостей.

**Spec:** `docs/superpowers/specs/2026-08-30-ui-rework-design.md`

## Global Constraints

- Палитра/тема НЕ меняются (янтарный/капс из frontend2 запрещены).
- Формулировки деловые: «работает / не работает + какая стратегия», БЕЗ «Проход открыт», БЕЗ hero-штампов.
- Одно действие на задачу: одна пара ▶/⏹ в панели действий; custom-карточка без кнопки.
- Пресеты/серверные API не менять (кроме явно помеченных шагов).
- Фронтенд живёт в `frontend/`; `frontend2/` — экспериментальный, не трогать, НЕ переносить его live-таблицу.
- Тестирование: `node --check frontend/js/app.js` после каждого JS-шага; живой тест — пользователем через webview; регрессия — полный прогон «Подбор стратегии».

**Interfaces:**

- Produces: методы `_liveBlockFor(profile)`, `_setLiveCurrent(profile)`, `_finishLiveProfile(profile, score)`; контейнер `#testLiveBlocks`; классы `.live-block`, `.live-block.active`, `.live-block.done`, `.live-block.expanded`.

- [ ] **Step 1: HTML** — внутри `#testLiveResults` после h3 добавить `<div id="testLiveBlocks"></div>` (таблицу-заглушку убрать или оставить пустой для совместимости).
- [ ] **Step 2: `_addResultRowImmediate` — группировка** — ключ строки: `profile|domain|test_type`; блок на профиль создаётся лениво: заголовок-кнопка (лампа + `profile · ok/n · N%` + стрелка) + tbody строк; `this._liveCurrent` — подсветка активного блока при смене profile.
- [ ] **Step 3: Делегированный обработчик** — клик по заголовку блока → toggle `.expanded` (сворачивание), `aria-expanded` синхронизировать.

- [ ] **Step 6: Проверка** — `node --check`; прогон теста (2-3 стратегии): блоки отдельные, активная подсвечена, завершённые сворачиваются, клик разворачивает, строки НЕ перемешиваются между стратегиями.
