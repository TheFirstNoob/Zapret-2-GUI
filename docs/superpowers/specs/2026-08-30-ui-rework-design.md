# UI Rework — Zapret 2 GUI (Pre-Release 0.5 → 0.6)

**Дата:** 2026-08-30 · **Статус:** утверждён пользователем (вариант Б: Тестер + Главная, лёгкое обновление без смены палитры)

## Контекст и цель

Фронтенд написан давно, код добавлялся слоями → каша: 4 карточки на одну задачу на Главной, живые строки тестера перемешиваются между стратегиями, итог теста размазан по трём блокам с несколькими кнопками. Цель: убрать визуальный шум, сгруппировать информацию по смыслу, одно действие на задачу. Палитра/тема НЕ меняются (янтарный акцент frontend2 отклонён пользователем).

## Секция 1: Главная — один блок вместо четырёх

Сейчас: Z2-карточка (PID/аптайм/селект/кнопки/служба), Z1-карточка, конфликт-карточка, тумблеры.

Будет:
- **Одна карточка «Обход»**: строка статуса `Z2 · работает · PID · стратегия · служба` → селект стратегии → одна пара ▶ Запустить / ⏹ Остановить → тонкая строка службы (статус + установить/удалить). Конфликт Z1/Z2 — красная строка ВНУТРИ карточки, не отдельная.
- **Zapret 1** — сворачиваемый подблок («Zapret 1 · развернуть»), по умолчанию свёрнут при неактивном Z1.
- **Тумблеры** — отдельная карточка (настройки ≠ действие), описания короче, дубли текста убраны.
- Убрать дубли: startResult/serviceStatus тексты → единая строка состояния.

## Секция 2: Тестер — группировка живых строк и единый итог

- Интро: 2 шага остаются; опции — чипы с галочкой (не чекбоксы).
- Прогресс: крупно «Тестируется: <стратегия> (N/M)».
- **Живой вывод: блок на стратегию** (заголовок `default · 12/13 · 92%` + строки; активная подсвечена; завершённые сворачиваются в итог-строку, клик — развернуть). Сервер уже шлёт `profile` в results (коммит 0cf0985).
- **Итог**: один вердикт-блок (заголовок + «лучшая: X» + ОДНА кнопка запуска) → компактная строка custom (источники, без кнопки) → таблица результатов без дубля «Рекомендуемая стратегия» → чипы заблокированных только при наличии.
- Журнал теста — `<details>` внизу.

## Секция 3: Общее

- `:focus-visible`, `prefers-reduced-motion`, системные шрифты (убрать JetBrains Mono-фолбэк).
- Разделители только смысловые; мелкие подписи → title-подсказки.

## Критерии приёмки

1. Главная: 2 карточки (Обход + Тумблеры) + сворачиваемый Z1, без дублей текста.
2. Тестер: строки не перемешиваются между стратегиями; итог = один вердикт + одна кнопка.
3. Палитра не меняется; фокус виден; шрифты системные.
4. Все прежние функции работают (тогглы, служба, Z1, тест, custom, диагностика) — регрессий нет.

## Порядок реализации

1. Спек + план (writing-plans) → TDD.
2. Сначала Главная (структура), затем Тестер (живой вывод), затем общее.
3. Тест пользователем через webview; пересборка дистрибутивов после приёмки.
