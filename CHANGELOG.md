# Changelog

## Pre-Release 0.2 (2026-08-23)

### 🔧 Исправлено

- **Отправка файлов в Discord** — главная проблема прошлой версии. Загрузки идут через отдельный домен Google Storage, который потерялся из списков обхода, плюс исправлена механика разрыва пакетов (multisplit). Теперь файлы отправляются, голос и прочее работает как раньше.
- **Зависания тестера** («остановка перед голым тестом» и другие) на русских Windows — причина найдена и устранена полностью (кодировки системных утилит).
- **Служба могла запустить устаревшую стратегию** — конфигурация службы теперь всегда обновляется перед установкой и запуском.
- **Тихие падения при запуске** — пресеты и параметры проверяются через `--dry-run` перед каждым запуском; битый пресет отклоняется с понятной ошибкой, не трогая работающую защиту.
- **Правки пользователей затирались** — встроенные списки/пресеты больше не перезаписываются при каждом запуске программы (только при обновлении версии).
- **Проверка пути установки** — честное предупреждение вместо мёртвого кода.
- **Параметры стратегий** — исправлены ошибки в пресетах fakedsplit / fake-disorder / fake-multidisorder / hostfakesplit / multisplit-* (tcp_ts на multisplit ломал доставку данных; битые аргументы hostfakesplit; multidisorder отправлял блоб вместо реальных данных).

### 🩺 Добавлено

- **Страница «Диагностика»** — одна кнопка проверяет права, путь установки, процесс, службу, конфликты и связь с Discord/YouTube, собирает отчёт для поддержки в буфер обмена.
- **Голый тест восстанавливает защиту** — после теста без обхода программа сама возвращает запущенную ранее защиту.

### ⚡ Улучшено

- **Тестер ускорен примерно в 3 раза** — полный прогон всех стратегий теперь занимает около минуты (кэш TTL-пробы, ускоренный tracert, быстрые таймауты curl, параллелизм 8).

## Pre-Release 0.1 (2026-07-29)

- Первая публичная предрелизная версия.
- Универсальная стратегия `default` (7 блоков фильтров), тестер, установка службы, тогглы GameFilter / Discord Voice / Auto Hostlist / DEBUG.
- Переход на curl-тестирование (вместо aiohttp), .txt-пресеты (вместо JSON-профилей), exe уменьшен с 43.9 до 18 МБ.
