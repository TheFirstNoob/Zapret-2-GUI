Параметры запуска
Применяются при старте Zapret 2. Не влияют на Zapret 1.
Настройки ниже относятся к Zapret 2 — сейчас запущен Zapret 1.
Игровые портыGameFilter Открывает обходу порты 1024–65535 (игры, голосовые чаты). Если игра не работает без него — включите.
Авто-списокAuto Hostlist Zapret сам добавит домен в обход, когда заметит блокировку. Держите включённым.
Общий IP-обходipset Обрабатывать весь трафик в известных блокируемых подсетях, а не только по спискам доменов. Сильнее грузит систему.
Discord VoiceUDP Отдельный обход голосового UDP-трафика Discord. Включайте только при PING ERROR / 5000 в голосовом чате.
DEBUG-логwinws2 Запись каждого пакета. Заметно повышает пинг и нагрузку на CPU. Только для разбора проблем по запросу.

Проверка системы
Права, конфликты, служба, пресет, связь и тип блокировки. Обычно 5–15 секунд.
Нажмите «Проверить», чтобы диагностировать окружение.
Как заполнять
example.comсайт и все его поддомены (www, api, m и любые другие)
api.example.comточечно — только этот поддомен (и его поддомены)
1.2.3.0/24IP-сеть или один IP-адрес — для блоков IP
Включения — Zapret обходит принудительно. Исключения — пропускает как есть (если обход мешает).
Один адрес на строчку. Ошибочные строки подсвечиваются — пока они есть, список не сохранится.
Домены — включения 0
Заблокированный сайт, которого нет в стандартных списках, — добавьте сюда: Zapret будет обходить его всегда, при любой стратегии.
1
Домены — исключения 0
Сайт, которому обход мешает (не открывается, тормозит), — добавьте сюда: Zapret будет пропускать его как есть.
1
IP-сети — включения 0
Подсети, которые обходятся всегда. Нужно при блокировке по IP-адресу, когда сайт не открывается независимо от имени.
1
IP-сети — исключения 0
Свои и локальные сети, которые обход не должен трогать. По умолчанию — приватные диапазоны.
1
CDN-стабилизация
Сканирует CDN-хосты под активной защитой и предлагает точечные правки списков: «В обход» — если DPI режет живой хост (stateful-класс, лечится десинком); «В стоп-лист» — если обход ломает живой хост. Полу-автономно: программа предлагает, вы подтверждаете одной кнопкой.
Сканирование занимает 1–2 минуты. Требуется работающая защита (winws2).

Будет сохранён ZIP с результатами теста, версией Windows и сетевыми настройками. Личные файлы и пароли не собираются.
