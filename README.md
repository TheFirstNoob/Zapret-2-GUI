## 🚀 Быстрый старт

> [!WARNING]
> Не запускайте программу **из архива**, из папки **Загрузки/Документы** и не кладите EXE **прямо на рабочий стол** — программа предупредит и подскажет, куда её перенести (например `C:\Zapret2GUI\`). Файлы из браузера несут пометку «из интернета», из временной папки теряются данные, а на столе после первого обновления появится россыпь папок программы.

**Portable (рекомендуется):**
1. Распакуйте `Zapret2GUI-portable.zip` в путь без кириллицы (например `C:\Zapret2GUI\`)
2. Запустите `install.cmd` один раз — создаст ярлык «Zapret 2 GUI» на рабочем столе и в Пуск
3. Запустите обход через ярлык (права администратора запросятся автоматически)

**Классический EXE:**
1. Распакуйте `Zapret2GUI.zip`, запустите `Zapret2GUI.exe`, согласитесь с UAC
2. Нажмите **Запустить** (стратегия `default`)

**Lite:**
1. Распакуйте и запустите `start-default.bat` (простой запуск) — или `service.bat` для меню: выбор стратегии, запуск/остановка, служба

**Если что-то не работает** — откройте **«Проверка системы»** (диагностика: права, путь, расположение, служба, тип блокировки DNS/IP/SNI) или **«Подбор стратегии»** (тест всех стратегий с рекомендацией и топ-3).

**Требования:** Windows 10/11 x64, права администратора, WebView2 Runtime (встроен в Win10/11, для portable).

## ✨ Возможности

- 🎯 **Универсальная стратегия `default`** — работает у большинства протестированных провайдеров; `default-alt` — вариант для капризных сетей
- 🧪 **Тестер** — live-таблица (доступность/хосты/статусы обновляются в процессе), голый тест (naked), вердикт с рекомендацией и **топ-3 стратегий**; **автоматическая сборка личной стратегии «custom»** из лучших сегментов каждой семьи (без `auto` — его механика отдельная) с проверкой движком; равные проценты объясняются прямо в вердикте, погрешность прогона (±1 домен) учитывается
- 🎨 **Селектор «Блоб фейка» + кнопка «Подобрать блоба»** — перебор TLS-блобов короткой батареей, победитель подставляется автоматически; блобы отсортированы по проверенной живучести
- 🔁 **Умный речек тестера** — если домен не пробился лучшей стратегией, программа сама перепроверит его с альтернативными блобами и сообщит «пробит с блобом X»
- 🩺 **Диагностика** — понятные объяснения вместо HTTP-кодов, **тип блокировки** (DNS / IP / SNI), **проверка DNS-подмены** по публичным резолверам, предупреждения о неудобном месте запуска (архив/Загрузки/Документы/рабочий стол), отчёт для поддержки (технические детали — для разработчика)
- 🎮 **Анализ приложения/игры (отдельная вкладка)** — не работает игра/программа? Укажите её процесс (или PID, из списка или руками) — увидите её сеть в реальном времени: куда ходит (IP + домены), состояния соединений (`SynSent` = возможный IP-блок), UDP-захват с направлением пакетов («шлём, но не получаем» = глушится → WARP), вердикт с рекомендацией. Процесс можно указать заранее — анализатор дождётся запуска
- ⚖️ **Спорные домены (отдельная вкладка)** — для доменов, которым обход одним провайдерам нужен, а у других под обходом ломается (например AWS): живая проба + тумблер «В обход» — включается осознанно, когда реально глушится
- 📡 **ASN-скан** — DPI-ландшафт вашего провайдера: 110 IP-проб с белым SNI, честная таксономия (OK / DETECTED / RST / SYN DROP / TIMEOUT) без моей защиты
- 🧩 **CDN-стабилизатор** — отдельная вкладка: находит сайты, страдающие от stateful DPI (игровые загрузки, Discord-медиа, видео), и лечит их точечными правками списков; кнопка «Применить все правки» — батчем
- 📦 **Служба Windows** — автозапуск после перезагрузки (winws2.exe напрямую, как Zapret 1) + **самовосстановление при падении** и верификация установленной командной строки (защита старых/сломанных систем от «кривой» установки)
- 🕵️ **Режим отладки** — журнал интерфейса и тестера (`ui_debug.log`) и сессии тестера (`test_session.log`) пишутся автоматически: при «программа что-то сделала непонятно» лог показывает точную цепочку
- ⚙️ **Тогглы**: GameFilter, Discord Voice (3 режима), Auto Hostlist, **Общий IP-обход** (обход по всем подсетям, как Zapret 1), DEBUG
- 📝 **Списки** — включения/исключения доменов и IP-сетей, нумерация строк, индикатор несохранённых изменений; пользовательские списки применяются ко **всем** стратегиям
- 🔀 **Zapret 1 (запасной)** — запуск/остановка классических стратегий из одного окна, компактная панель-фолбек
- 📥 **Обновление из программы** — новая версия скачивается и ставится прямо из окна (GitHub → зеркало), настройки и пользовательские списки сохраняются, перед обновлением — автоматический бэкап; если параметры службы устарели, программа сама предложит её переустановить
- 💾 **Резервная копия настроек** — экспорт/импорт конфига и пользовательских списков одним файлом (вкладка «Списки»)
- 🩹 **Кнопка «Починить»** — самолечение службы драйвера WinDivert: битый путь от старой установки исправляется, отключённая служба включается; если драйвер «помечен на удаление» — честно скажет, что нужна перезагрузка
- 🔄 **Переход с Zapret 1** — если при установке найдена служба Zapret 1, программа предложит остановить и удалить её в один клик (то же, что «Remove Services» из service.bat)
- 🚀 **Быстрый старт** — карточка из 3 шагов для новичка (запустить → проверить → подобрать стратегию); экспертные инструменты убраны в сворачиваемую группу навигации

## Стратегии (пресеты)

| Пресет | Подход |
|---|---|
| `default` | **Универсальная** — fake (drop + repeats) + multisplit |
| `default-alt` | То же, но discord-фейки с **`tls_mod=rnd,dupsid`** (случайные поля + session_id из реального hello) — DPI не может зафиксировать «всегда одинаковый фейк». Попробуйте, если `default` флакает на Discord |
| `auto` | То же, но с **автопереключением стратегий** при неудачах (circular). Попробуйте, если `default` не пробивает ваш провайдер |
| `tcpmd5-fake` | Fake + `tcp_md5` — для сетей, где фейки фингерпринтятся по TCP-опциям |
| `fake-only` | Только fake |
| `fakedsplit` | Fake + fakedsplit |
| `fake-disorder` | Fake + disorder (кастомная lua) |
| `fake-multidisorder` | Fake + multidisorder |
| `hostfakesplit` | Подмена хоста + разрыв |
| `multisplit-pure` / `multisplit-seqovl` | Чистые разрывы |

### Как работает `auto` (автопереключение)

`auto` — та же логика, что `default`, но с **самовосстановлением**: внутри каждого сегмента зашиты три набора правил обработки (полный `fake + multisplit`, только `fake`, только `multisplit`) и оркестратор `circular`.

- Он следит за соединением: если видит **3 неудачи** (RST от сервера или повторные передачи одного пакета) — переключает сегмент на следующий набор правил и продолжает по кругу.
- Если соединение после переключения ожило — счётчик сбрасывается, и сегмент возвращается к сильному набору.
- Если неудач не было **дольше 60 секунд** — счётчик тоже сбрасывается (старые сбои не накапливаются).

**Когда использовать:** если `default` на вашей сети периодически «отваливается» — `auto` сам подстроится. Цена — чуть больше служебного трафика (перехват входящих ответов для детекта сбоев). Если `default` стабилен — `auto` не нужен.

### Как собирается `custom` (личная стратегия)

После прогона тестера программа строит **персональную стратегию под вашу сеть**:

1. Каждый домен из теста привязывается к «семье» по моим спискам: **Discord**, **Google**, **General**.
2. Для каждой семьи считается процент пробития **каждой** стратегии — и выбирается лучшая:
   - сегмент Discord ← у стратегии с лучшим Discord-результатом;
   - сегмент Google ← у лучшей по Google;
   - сегмент General ← у лучшей по General.
3. `auto` в сборке не участвует: его механика (`circular`-перебор) — отдельный режим со своей lua-инициализацией, а не сегмент. `custom` — это только композиция честных сегментов.
4. Непроверяемые тестером сегменты (голос, медиа-порты, QUIC) всегда берутся из `default` — там они проверены.
5. Собранный `custom` **проверяется движком** (dry-run + реальный запуск): если не запустился — в вердикте честно отобразится ошибка.

`custom` пересобирается **каждым** прогоном теста — старая версия в новом прогоне не участвует, так что стратегия всегда свежая. Если разные стратегии лучшие в своих семьях — `custom` соберёт их вместе, и это может пробивать больше, чем любая одна стратегия.

### Равные проценты: кого выбирает тестер?

Порядок прогона детерминирован: `default` тестируется первым, `auto`/`custom` — последними. При равных результатах рекомендуется **первая протестированная** (обычно `default`) — и вердикт прямо это объясняет: стратегии равнозначны (пресеты под разные сети/провайдеры), при флаках переключайтесь на другую из списка. Погрешность прогона учитывается: разница в **±1 домен** от лучшей считается практически равной (один случайный флак двигает рейтинг на целый домен).

## 🔍 Прозрачность: что программа делает с системой и данными

Ничего не скрываем — вот полный список того, что программа делает:

**Система (только необходимое для обхода):**
- при запуске обхода загружается драйвер **WinDivert** (идёт в комплекте, open-source) — он перехватывает и модифицирует сетевые пакеты на вашем ПК; служба драйвера создаётся автоматически;
- **служба автозапуска** ставится только по вашему нажатию («Установить службу»);
- для части стратегий включается системная настройка **TCP timestamps** — этого требует движок (состояние видно в «Проверке системы»; вернуть как было: `netsh int tcp set global timestamps=disabled`);
- **hosts-файл программа НЕ трогает** — приложенный `hosts.txt` вы подключаете сами, если он нужен;
- все свои файлы программа создаёт только в своей папке.

**Данные:**
- **телеметрии нет**: никакая статистика, идентификаторы и личные данные никуда не отправляются;
- журналы (`ui_debug.log`, `test_session.log`) пишутся локально, в папке программы;
- отчёты для поддержки создаются локально и передаются, только если вы сами их отправите;
- галочка согласия в тестере — для случаев, когда вы добровольно делитесь отчётом.

**Сеть:**
- проверка обновлений — запрос к GitHub/зеркалу; обновление ставится только по вашему нажатию;
- диагностика/тестер/сканы делают сетевые пробы к публичным сайтам (по ним и определяется блокировка);
- больше никаких обращений «наружу» нет.

**Чужие компоненты:** движок `winws2` + lua-скрипты — [zapret2](https://github.com/bol-van/zapret2), драйвер — [WinDivert](https://github.com/basil00/WinDivert); полный список — в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## ❓ Частые вопросы

**Обход не запускается / кнопка не работает**
Проверьте: путь без кириллицы (`C:\Zapret2GUI\`), права администратора, нет второго Zapret (WinDivert конфликтует), программа не запущена из архива/Загрузок. Откройте «Проверка системы» — диагностика покажет точку отказа.

**Ничего не пробивается (все стратегии 000)**
Запустите «Подбор стратегии» — тестер сам переберёт пресеты, соберёт `custom` и даст вердикт. Если не помогло — «Проверка системы» покажет тип блокировки (DNS/IP/SNI); при IP-блоке поможет общий IP-обход или hosts/WARP.

**YouTube/Google «красные» в тестере, но в браузере работают**
Это нормально: TCP-проба «чужим клиентом» (curl) сквозь обход не показательна — браузер ходит через QUIC. Такие хосты помечаются «≈ QUIC» и не считаются провалом. Проверяйте реальный опыт в браузере.

**Дискорд работает, но голос/звонки не идут**
Попробуйте тоггл Discord Voice → «UDP-длина». Если не помогло — смените голосовой регион сервера в клиенте Discord.

**Discord не открывается, а остальное работает**
Включите «Альт-режим Discord» в «Экспертных инструментах» и перезапустите обход (если стоит служба — переустановите её кнопкой). Это прежний режим обработки Discord, и он касается **только Discord**: остальные сервисы работают и без него. Если и на альт-режиме Discord иногда капризничает — это гонка с фильтрами провайдера, а не поломка программы: попробуйте другую стратегию или обновление позже.

**Игра не подключается к серверу (выкидывает в меню), хотя авторизация работает**
Откройте **«Игровые блокировки»** (экспертные инструменты): для конфликтной игры включите домены (авторизация/лобби) и UDP-фикс (подключение к серверам). Wardogs уже добавлен и включён. Домены применяются сразу к новым подключениям, UDP-фикс — после перезапуска обхода (службу переустановите кнопкой). Если игра всё равно не заходит — вкладка «Анализ приложения» покажет, куда она стучится: диапазон/порт можно дописать в её запись.

**«Failed to remove temporary directory _MEI…» при закрытии EXE**
Исправлено в 0.8 (служба больше не привязывалась к временной папке распаковки). Если сообщение появляется на старой версии — безвредно: папка была занята (дочерний WebView2 / антивирус), мусор подчищается автоматически при следующем запуске.

**Защитник ругается на программу**
Это ложное срабатывание поведенческой эвристики (драйвер перехвата + служба) — так же бывает и на оригинальном zapret. Выберите в уведомлении «Разрешить». Подробнее — в разделе «Антивирусы».

**GitHub скачивается медленно/не скачивается**
После 0.6 GitHub лечится самим обходом. Если всё ещё нет — см. раздел про hosts/WARP ниже.

## 📄 hosts.txt — запасной инструмент

С 0.6 основные блоки (Discord, GitHub, YouTube) обходятся самим движком. Но есть вещи, которые движок не берёт — для них приложен готовый [`hosts.txt`](hosts.txt) (469 строк, синхронизирован с репозиторием Zapret 1 от Flowseal + мои дополнения):

**Что внутри:**
- **Discord-голос: Finland-серверы** (`finland10000-10019.discord.media`) — пиннинг на рабочий IP. Если голосовые каналы не открываются/обрываются — это первый кандидат (взято из Zapret 1, где проверено)
- **ИИ-сервисы через антиблок-работник** — ChatGPT, Gemini/AI Studio, Claude, xAI, Spotify, Deepl и др.: гео-обход, когда сервис отвечает «регион не поддерживается»
- **GitHub-fix** — githubusercontent/raw/objects/avatars через Fastly-эджи (если обход не справился на вашей сети)
- **Антитрекер-заглушки** — мусорные домены на `0.0.0.0`

**Как применять:**
1. Откройте `C:\Windows\System32\drivers\etc\hosts` (от администратора)
2. **Дописывайте строки из hosts.txt в конец файла** — никогда не заменяйте файл целиком (полная замена может лишить службу DNS прав на чтение, и Windows будет молча игнорировать hosts)
3. `ipconfig /flushdns`

**Важно:** записи hosts не мешают другим программам и сайтам — это точечные пиннинги конкретных доменов, остальной трафик не затрагивается. Если какой-то IP «умер» (сайт перестал открываться, а без hosts — открывается) — удалите его строки или замените на запасные IP (списки в комментариях файла).

### 🌐 DNS — если сайты открываются «через раз»

Иногда помогает смена системного DNS (заблокированный DNS у провайдера отдаёт кривые ответы):

| Провайдер | Основной | Альтернативный |
|---|---|---|
| **Google Public DNS** | `8.8.8.8` | `8.8.4.4` |
| **Cloudflare** | `1.1.1.1` | `1.0.0.1` |
| **Quad9** (блокирует вредоносные) | `9.9.9.9` | `149.112.112.112` |

Меняется в: *Параметры → Сеть и Интернет → Wi-Fi/Пропускная способность → Свойства адаптера → IP-назначение → DNS-сервер → Вручную*.

### 🌐 YouTube открывается, но пишет «нет интернета» (внутри ютуба)

Страница грузится (обход работает), но видео не идёт — плеер ходит на медиа-хосты `*.googlevideo.com` через **DNS-резолвер браузера (DoH)**, и резолвер может отдавать недоступные кэш-серверы. Лечится заменой DNS-провайдера **внутри браузера**:

| Браузер | Где менять |
|---|---|
| Opera / Opera GX | Настройки → Конфиденциальность → Use DNS over HTTPS → сменить провайдера (или выключить) |
| Chrome / Edge | Настройки → Конфиденциальность → Безопасность → Use secure DNS → сменить/выключить |
| Firefox | Настройки → Приватность → DNS over HTTPS → сменить/выключить |

Попробовать по очереди: **Quad9 (9.9.9.9)** → **Cloudflare** → выключить DoH (будет системный). Актуально для всех браузеров с встроенным DoH — резолвер влияет на то, к какому кэш-серверу YouTube направит видео. С системным DNS работает та же логика (см. таблицу выше).

**Бонус-советы с форума Zapret 1 (Ростелеком):**
- YouTube «тормозит/через раз» → **отключите QUIC в браузере**
  (chrome://flags → Experimental QUIC protocol → Disabled)
- Смена DNS на **9.9.9.9 / 149.112.112.112** заметно улучшает загрузку
  видео на РТК

## 🦠 Антивирусы (важно)

WinDivert — инструмент перехвата трафика, на котором работает zapret. Он встречается и в хороших, и в плохих программах, поэтому часть антивирусов относит его к RiskTool/PUA. Вирусом он не является.

**Ложные срабатывания — обычное дело для таких инструментов.** Защитник Windows иногда помечает даже официальные архивы zapret от bol-van (детект вида `Trojan:Win32/…!cl`), а иногда — мои сборки: только за драйвер перехвата и установку службы. Это поведенческая эвристика, а не заражение.

**Что делать, если Защитник пометил файл:** в уведомлении выберите **«Разрешить»** (в журнале защиты — «Разрешить на устройстве» или «Восстановить»). Этого достаточно, программа продолжит работать.

**Исключения — на ваше усмотрение.** Исключение означает «доверять этому файлу/папке полностью» — если добавляете, делайте это осознанно. Я не прошу вносить в исключения.

**Меньше всего ложных реакций** — у `portable` (запускается официальный Python, без самосборного EXE) и `lite` (только .bat и бинарники движка). Служба ставится напрямую — `winws2.exe` бинарником, как в Zapret 1, без cmd-обёрток, на которые поведенческие детекты реагируют чаще.

## ⚠️ Известные особенности

- **Кириллица в пути** — не запускается без коротких имён 8.3. Держите путь ASCII (`C:\Zapret2GUI\`)
- **Загрузки/Документы/архив/рабочий стол** — программа предупредит: данные во временной папке теряются, файлы из браузера проверяются агрессивнее, папки могут синхронизироваться. Держите программу в отдельной папке (`C:\Zapret2GUI\`)
- **Killer NIC** — конфликтует с WinDivert; отключите Bandwidth Control
- **Яндекс.Браузер** принудительно подменяет DNS — тестируйте в Firefox/Chrome
- **Два Zapret одновременно** — нельзя: WinDivert-фильтры конфликтуют
