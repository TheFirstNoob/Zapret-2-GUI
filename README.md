# Zapret 2 GUI

GUI-обёртка для **Zapret 2** (winws2 / lua-desync) — обход DPI/ТСПУ на Windows без VPN.

> [!IMPORTANT]
> Я не буду исключать что программа делалась с помощью ИИ. Я делюсь своим рабочим результатом который работает у меня и пользователей моего дискорда. Все дальнейшие отзывы уже были по принципу "друг посоветовал" и так далее. Иначе говоря работа программы подтверждена!

## 🎁 Какую версию скачать

| Архив | Что внутри | Для кого |
|---|---|---|
| **`Zapret2GUI-portable.zip`** ⭐ | Полный GUI на официальном Python (без сборщика, `pythonw.exe` подписан PSF) — **рекомендуется** | Все; Защитник относится спокойнее всего |
| **`Zapret2GUI.zip`** | Классический GUI одним EXE (PyInstaller) | Кому удобен один файл |
| **`Zapret2GUI-lite.zip`** | Только winws2 + батники, без Python и GUI (как Zapret 1) | Минимализм / очень строгие антивирусы |

Все три содержат одну и ту же стратегию `default`. SHA256 к portable-архиву лежит рядом.

## 🚀 Быстрый старт

**Portable (рекомендуется):**
1. Распакуйте `Zapret2GUI-portable.zip` в путь без кириллицы (например `C:\Zapret2GUI\`)
2. Запустите `install.cmd` один раз — создаст ярлык «Zapret 2 GUI» на рабочем столе и в Пуск
3. Запустите обход через ярлык (права администратора запросятся автоматически)

**Классический EXE:**
1. Распакуйте `Zapret2GUI.zip`, запустите `Zapret2GUI.exe`, согласитесь с UAC
2. Нажмите **▶ Запустить** (стратегия `default`)

**Lite:**
1. Распакуйте, запустите `service.bat` → меню: выбор стратегии, запуск/остановка, служба

**Если что-то не работает** — откройте **«Проверка системы»** (диагностика: права, путь, служба, тип блокировки DNS/IP/SNI) или **«Подбор стратегии»** (тест всех стратегий с рекомендацией).

**Требования:** Windows 10/11 x64, права администратора, WebView2 Runtime (встроен в Win10/11, для portable).

## 🦠 Антивирусы (важно)

> WinDivert — инструмент перехвата трафика, необходимый для работы zapret. Он может использоваться как хорошими, так и плохими программами, но сам по себе не является вирусом. Некоторые антивирусы относят его к RiskTool/PUA.

- **Защитник Windows** может пометить классический EXE (поведенческие эвристики: установка службы, загрузка драйвера). Это ложное срабатывание. Решения:
  - используйте **portable** или **lite** версию — им флаги прилетают заметно реже;
  - добавьте папку в исключения Защитника: *Параметры → Конфиденциальность и безопасность → Безопасность Windows → Защита от вирусов и угроз → Управление параметрами → Исключения*;
  - отправьте ложное срабатывание в Microsoft: https://www.microsoft.com/en-us/wdsi/filesubmission
- Служба устанавливается **как в Zapret 1** — winws2.exe напрямую бинарником (без cmd-обёртки), что не вызывает реакции.

## Возможности

- 🎯 **Универсальная стратегия `default`** — работает у большинства протестированных провайдеров
- 🧪 **Тестер** — все стратегии, голый тест (naked), вердикт, статус Discord/YouTube, кнопка «Запустить рекомендованную», автопроверка движка (профили/списки)
- 🩺 **Диагностика** — права, путь, процесс, служба, конфликты, связь + **тип блокировки** (DNS / IP / SNI через SNI-swap проверку) + отчёт в буфер
- 📦 **Служба Windows** — автозапуск после перезагрузки (winws2.exe напрямую, как Zapret 1)
- ⚙️ **Тогглы**: GameFilter, Discord Voice, Auto Hostlist, **Общий IP-обход** (обход по всем подсетям, как Zapret 1), DEBUG
- 📝 **Списки** — исключения/включения доменов + IP-исключения
- 🔀 **Менеджер Zapret 1** — запуск/остановка классических стратегий из одного окна

## Стратегии (пресеты)

| Пресет | Подход |
|---|---|
| `default` | **Универсальная** — fake (drop + repeats) + multisplit |
| `fake-only` | Только fake |
| `fakedsplit` | Fake + fakedsplit |
| `fake-disorder` | Fake + disorder (кастомная lua) |
| `fake-multidisorder` | Fake + multidisorder |
| `hostfakesplit` | Подмена хоста + разрыв |
| `multisplit-pure` / `multisplit-seqovl` | Чистые разрывы |

## Сборка из исходников

```bat
git clone https://github.com/TheFirstNoob/Zapret-2-GUI.git
cd Zapret-2-GUI
python main.py                  :: запуск из исходников
python build.py                 :: классический EXE  -> dist\Zapret2GUI.exe
python build_portable.py        :: portable (без сборщика) -> Windows build\Zapret2GUI-portable.zip
python build_lite.py            :: lite на .bat     -> Windows build\Zapret2GUI-lite.zip
```

## Известные особенности

- **Кириллица в пути** — не запускается без коротких имён 8.3. Держите путь ASCII (`C:\Zapret2GUI\`)
- **Killer NIC** — конфликтует с WinDivert; отключите Bandwidth Control
- **Яндекс.Браузер** принудительно подменяет DNS — тестируйте в Firefox/Chrome
- **Два Zapret одновременно** — нельзя: WinDivert-фильтры конфликтуют
